# Livent Web

Versión web de la aplicación Livent para la gestión y descubrimiento de eventos locales.

## Tecnologías

- **Frontend:** React 19 + Vite
- **Estilos:** Tailwind CSS
- **Backend:** Supabase (Auth & Database)
- **Iconos:** Lucide React

## Configuración Local

1. Instalar dependencias:

   ```bash
   npm install
   ```

2. Configurar variables de entorno:
   Crea un archivo `.env` basado en `.env.example` con tus credenciales de Supabase y Stripe.

3. Ejecutar en desarrollo:

   ```bash
   npm run dev
   ```

## Despliegue

El proyecto está configurado para ser desplegado en **Vercel**.
